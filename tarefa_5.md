# Tarefa Optativa 5

## 1. Escrever um programa em qualquer linguagem para:

1.1 Construir a curva traçada por um ponto P de um disco de raio r que rola sem escorregar sobre a face interna de um aro de raio R > r, ou seja, a hipociclóide dada por:

```
x = (R - r) cos θ + r cos(((R - r) / r) θ)
y = (R - r) sin θ - r sin(((R - r) / r) θ)
```

1.2 Mostrar, em forma de animação, o processo de geração da hipociclóide referida no item 1.1.

1.3 Apresentar alguns instantâneos desse processo.

1.4 Apresentar exemplos de hipociclóides traçadas para 4 distintas razões R/r.

1.5 Calcular o raio de curvatura em diferentes posições da hipociclóide.

1.6 Desenhar os versores tangente e normal principal em diferentes pontos da hipociclóide.

1.7 Admitindo uma lei horária dada por

```
θ(t) = ω t, com ω = π/60 rad/s
```

calcule a velocidade e a aceleração de P na forma cartesiana e em coordenadas intrínsecas para 3 diferentes instantes.

## 2. Escrever um programa em qualquer linguagem para:

2.1 Construir a curva C definida por

```
x = λ    y = λ²    z = λ³
```

onde λ ∈ ℝ, λ ≠ 0 é um parâmetro de livre escolha.

2.2 Calcule o raio de curvatura em 3 pontos de C, livremente selecionados.

2.3 Calcule e desenhe os versores τ, n, b do triedro de Frenet para os pontos de C selecionados no item 2.2.
